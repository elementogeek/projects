~/projects/setup

================

## pitch

Notes on turning a bare Mac into a workshop for game development and media work, driven by Claude Code. The docs act as shared memory across chats.

## engine and tools

  • Godot 4.2.2 in /Applications/Godot.app, with the 4.2.2 Web export templates.
  • GUT (Godot Unit Testing), vendored in addons/gut and run headless.
  • yt-dlp, installed with Homebrew.
  • ffmpeg, already present.
  • Python 3 for simulations and the art and audio generators.

## claude code

Claude Code drives all of the above.

  • The gstack skill suite lives in ~/.claude/skills, about 58 skills: browse, qa, review, ship, plan reviews, design, and safety guards.
  • The superpowers plugin is the only plugin enabled in user settings.
  • A project .claude/launch.json defines the preview server.

## shared memory

A CLAUDE.md at the workspace root is read by every Claude chat. Its rules:

  • The code is the source of truth. Config tables are rewritten to match the code before they are trusted.
  • The changelog is append-only and dated. Other chats' entries are never deleted.
  • Godot gotchas, testing pitfalls and the web-build recipe are kept in the same file.
  • Supporting files: an AGENTS.md for the game repo, a TODO.md backlog that is surfaced at session start, and memory notes.

## layout

  • ~/CLAUDE/ is the workspace. It holds CLAUDE.md, the VirusPvP project, and the Python simulation scripts.
  • ~/ichat-viewer is its own git repository.
  • The Godot project exports a Web preset to build/web, which is ready for itch.io.
  • Local web testing uses build/serve.py, a static server that sends the COOP/COEP headers Godot 4.2 requires.

## shell functions

Added to ~/.zshrc:

ytdl <url>    # YouTube to ~/Downloads as H.264 MP4
ytdla <url>   # audio only, as MP3

ytdl keeps the H.264 download when YouTube offers it, and transcodes only when the codec is something else, such as AV1.

## gotchas

  • Godot 4.2 web builds need cross-origin isolation (COOP/COEP headers). A plain http.server never loads them.
  • Bitmap fonts must go through the ImageFont importer; a hand-built FontFile renders tofu boxes.
