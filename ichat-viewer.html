## pitch

A browser tool that opens old Apple iChat .ichat transcripts that macOS and paid apps refuse to read.

Live: elementogeek.github.io/ichat-viewer
Source: github.com/elementogeek/ichat-viewer

## problem

Some .ichat files are NSKeyedArchiver binary plists with stray bytes in front of the bplist00 magic. Standard parsers fail on them because the file does not start where they expect.

## how it works

  • Skips the junk before the magic bytes.
  • Hand-decodes the bplist and the keyed archive.
  • Renders the messages as chat bubbles, with the sender shown on both sides.
  • Drag and drop a file onto the page.
  • Runs 100 percent in the browser. Nothing is uploaded and there is no backend.

## usage

Open the live page and drop an .ichat file onto it. The transcript renders in the page.

Outside the browser, ichat2html.py converts a .ichat file into a standalone .html file. See the repo README.

## tech

  • Vanilla HTML and JavaScript, no framework. The parser also runs in Node.
  • A Python CLI converter (ichat2html.py) uses plistlib for the same conversion.
  • Files: index.html, ichat.js, ichat2html.py, README.md.
  • Hosted on GitHub Pages. There is no build step: the page is static files served as they are.
